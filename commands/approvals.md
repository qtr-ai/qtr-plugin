Go through the changes waiting for the user's approval in QTR, using the qtr skill.

1. Call `list_pending_proposals`. In apps that show views, each change appears with Approve and Reject.
2. For each change, say what it would change and where it came from.
3. Approve or reject only the ones the user decides on, one id at a time, with `approve_proposal` or `reject_proposal`.
